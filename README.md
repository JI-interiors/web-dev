# Web Services Agency — V5 CRM Sales & Delivery

V5 extends the backend foundation into a basic sales/delivery CRM.

### Added
- Customers table
- Lead → customer conversion API foundation
- Quotes table and admin quote creation
- Projects table and admin project creation
- Tasks, invoices, payments and messages database schema
- CRM navigation for Customers / Quotes / Projects
- Lead statuses: New, Contacted, Quoted, Won, Lost
- Project statuses: Planning, Design, Development, Review, Live, On Hold

### Production roadmap
Next connect:
1. Real customer authentication and client portal
2. Invoice generation
3. Payment gateway + webhook reconciliation
4. Email and WhatsApp notifications
5. Tasks and project activity
6. Quote acceptance by customer
7. Service/package catalog
8. File uploads
9. Audit logs and permissions
10. Backups, rate limiting and full production security

The system is still a development foundation. Do not use it for real customer data or live payments until production security and deployment are completed.
